문제

제네릭 메서드를 바탕으로 점수 및 단어를 정렬하는 문제입니다 이를 해결하는 다음 프로그램에 대해 빈칸을 채우세요 
86 89 90
apple banana carrot

	public static void main( String[] args ) { 
		[] scores = new [] { 90, 89, 86 };

	}
